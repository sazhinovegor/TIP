### Задача №1 — Обмен значений без третьей переменной

Даны две переменные `a` и `b`. Нужно поменять их значения местами, не используя третью (временную) переменную. Решение через сложение и вычитание: сначала кладём в `a` сумму обоих чисел, потом вычитаем из неё `b` — получаем исходное `a` в `b`, и наоборот.

### Задача №2  — Произведение факториалов

Нужно вычислить F(n) = 1! × 2! × 3! × ... × n!. Сделано за один проход: на каждом шаге домножаем текущий факториал на `i` (получаем `i!`), потом домножаем общий результат на этот факториал. Тип `unsigned long long` — чтобы влезли большие числа (до 20! включительно).
