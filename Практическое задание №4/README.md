**Задание:
Фрилансер Татьяна устала тапать хомяка, поэтому пошла на завод по получению натуральных чисел. За станком Татьяны есть только 2 кнопки: "-1" и ":2". На экране у Татьяны появляются два числа А и В (А>B). Татьяна может разделить число на 2, если оно чётное, либо вычесть 1 в противном случае.
Необходимо вывести последовательность нажатий кнопок КАЖДЫЙ В ОТДЕЛЬНОЙ СТРОКЕ Татьяной, которая преобразует число А в число В за минимальное количество нажатий.
Дано два натуральных числа A и B (A>B).
Напишите алгоритм для Татьяны, который преобразует число A в число B и при этом содержит минимальное число команд. Команды алгоритма нужно выводить по одной в строке, первая команда обозначается, как -1, вторая команда как :2.**
